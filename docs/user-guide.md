# 使用指南

先按 [快速开始](../README.md#快速开始)启动服务并登录。

## 创建第一个项目

在项目工作空间点击创建项目，填写名称、目标、开始日期和结束日期，再核对确认。创建者是项目负责人，项目初始包含「通用工作」分组。示例项目可用于了解页面，正式项目则从空白开始。

## 录入任务并查看计划

1. 打开项目的「任务管理」，选择「新建任务」。填写标题和工作分组，按需设置负责人、日期和优先级。
2. 在列表或看板打开任务详情。由有权限的成员推进状态。关键交付可指定独立验收人，提交成果后由验收人核对。
3. 打开「完整计划」，查看甘特图。项目管理人员可预览排期或依赖变更，核对影响后保存，也可以发布基线以追踪计划偏差。

项目逐步展开后，可在「完整计划」切换到里程碑视图，在「统计分析」查看进度和负荷，在「风险中心」处理风险与预警。

## 添加项目成员

1. 系统管理员在右上角用户菜单打开「用户管理」，为成员开通账号。初始密码只显示一次，请通过私密渠道交给成员。
2. 项目负责人或项目管理员在项目的「成员与设置」添加现有账号并选择项目角色。
3. 新成员首次登录时修改初始密码，然后从工作空间打开有权限的项目。

飞书通知是可选功能。需要使用时，请先在系统设置配置主密钥，再在项目的「成员与设置 → 通知与集成」配置群机器人。发送测试卡片前请核对目标群和消息内容。
